- (decision) Paradigm: pipes-and-filters DAG via LangGraph StateGraph. One Python orchestrator process; each of the 6 PRD nodes (Plan, Locate, Implement, Test, Self-Review, Push) is a pure function over a single shared RunState, never mutating external files except Implement's own writes.
- (constraint) Investigated repo: PHP ^8.1, Laravel ^10.10, phpunit ^10.1, DB_CONNECTION=mysql in .env with no testing-env DB override in phpunit.xml (sqlite lines present but commented out) -- means php artisan test currently risks hitting the live self_management_app MySQL DB unless overridden.
- (decision) AD: Test node forces DB_CONNECTION=sqlite / DB_DATABASE=:memory: as process env overrides for the php artisan test invocation only, regardless of the app's real .env -- tests must never touch the production MySQL DB. Binds: FR-2 Test node. Prevents: a Run corrupting real user financial data via its own test pass.
- (assumption) Researched AWS free tier 2026: legacy accounts (pre 2025-07-15) get 750 EC2 t2/t3.micro hours/month for 12 months; NEW accounts instead get 00 credit for 6 months then standard pay-as-you-go -- no perpetual free EC2 tier for new accounts. Lambda's free tier (1M req + 400k GB-s/month) IS perpetual/always-free regardless of account age.
- (question) Is Joseph's AWS account legacy (pre-2025-07-15) or new? Determines whether an always-on EC2 instance is actually free. Architecture below is designed to be safe either way by minimizing EC2 uptime rather than assuming legacy status.
- (decision) AD: Compute substrate is a single on-demand EC2 instance (t3.micro), started only when a Ticket is detected and stopped by the orchestrator itself immediately after the Run ends (success, failure, or abort). Binds: all 6 nodes (Implement/Test need real PHP+Composer+Laravel, ruled out Lambda for those). Prevents: 24/7 EC2 billing exposure under the 2026 new-account free-tier policy change; keeps usage minimal under either free-tier structure.
- (decision) AD: Trigger is a perpetually-free AWS Lambda on an EventBridge schedule (every 5 min, matching PRD FR-1's 5-minute detection assumption), polling GitHub Issues API for the agent-ready label. On match it starts the EC2 instance via boto3 and passes the issue number as instance user-data/tag. Binds: FR-1. Prevents: needing a public webhook endpoint (API Gateway) or an always-on listener, resolving PRD Open Question 1 in favor of polling.
- (decision) AD: Single persistent git working copy lives on the EC2 instance at a fixed path. Every Run begins with git fetch && git reset --hard origin/main before Plan runs, and the orchestrator re-runs that same reset after Push (success) or on any abort/failure path. Binds: all nodes. Prevents: state (uncommitted files, a previous failed Run's partial diff) leaking from one Run into the next.
- (decision) AD: Denylist is one shared module (denylist.py) listing protected paths -- app/Http/Controllers/PaymentController.php, app/Http/Controllers/WebhookController.php, any Cashier/Stripe config, database/migrations/**, auth-related controllers/middleware. Imported by both Locate and Push nodes, never re-implemented per-node. Binds: FR-5. Prevents: the two enforcement points (Locate, Push) drifting into different path lists.
- (decision) AD: Exactly one GitHubClient wrapper (issue read/comment/close, git push) and one ClaudeClient wrapper (all LLM calls) exist; nodes call these, never the raw PyGithub/anthropic SDKs directly. ClaudeClient logs token usage to the SpendLedger on every call, before returning to the caller. Binds: all nodes, FR-3. Prevents: spend-tracking or retry logic being duplicated or forgotten in an individual node.
- (decision) AD: SpendLedger is a single JSON file on the EC2 instance's persistent disk, append-only, summed at orchestrator startup and before/after every Claude call; the orchestrator refuses to start a new Run once cumulative spend >= the RM100 Spend Cap. Binds: FR-3.
- (decision) AD: Every Run's Run Log (plan, diffs, test output, node-by-node trace, final outcome) is written to S3 (free-tier, <5GB for this volume) under runs/{issue-number}/{run-timestamp}/, in addition to local disk. Binds: FR-2's Run Log requirement. Prevents: losing the audit trail if the EC2 instance is ever replaced/terminated (consistent with on-demand-instance decision above).
- (decision) AD: Secrets (GitHub PAT, Claude API key) live in AWS SSM Parameter Store as SecureString standard parameters (free tier), read once at orchestrator startup -- not Secrets Manager, which is not free-tier.
